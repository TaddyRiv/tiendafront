## 🚫 Reglas anti-procrastinación

### La regla de los 2 minutos
> Si una tarea toma menos de 2 minutos, **hazla ahora mismo**.

### La técnica Pomodoro
Divide el trabajo en bloques con descansos:
- 🍅 **25 minutos de trabajo enfocado** (sin teléfono, sin redes sociales)
- ☕ **5 minutos de descanso**
- Cada 4 pomodoros → descanso de 15-30 minutos

### La regla de "no romper la cadena"
- Usa un calendario en papel o digital
- Marca con ✅ cada día que cumples tu rutina
- **El objetivo es no romper la cadena** de días consecutivos

### Bloquear distracciones
- Silencia notificaciones del celular durante bloques de estudio
- Usa aplicaciones como **Cold Turkey**, **Freedom** o **Forest** para bloquear redes sociales
- El celular va en otra habitación durante las sesiones de trabajo

### La regla de "primero lo difícil"
- Haz la tarea más difícil o que más te cuesta **al inicio del día**, cuando tienes más energía
- Nunca empieces por lo fácil o por redes sociales

## 💻 Plan de aprendizaje de desarrollo (Tecno Web + proyecto)

### Nivel actual → Objetivo
Pasar de estudiante a desarrollador con portafolio real.

### Ruta de aprendizaje semanal

**Semanas 1-4: Fundamentos web sólidos**
- [ ] HTML semántico (estructura correcta)
- [ ] CSS con Flexbox y Grid
- [ ] JavaScript ES6+ (funciones, arrays, objetos, promesas)
- [ ] Git y GitHub básico

**Semanas 5-8: React (ya tienes tiendafront para practicar)**
- [ ] Componentes funcionales y props
- [ ] useState y useEffect
- [ ] React Router
- [ ] Context API (ya está en el proyecto)
- [ ] Llamadas a APIs con Axios

**Semanas 9-12: Aplicación práctica**
- [ ] Trabajar en tiendafront: agregar funcionalidades reales
- [ ] Crear tu propio proyecto desde cero
- [ ] Subir proyectos a GitHub con README
- [ ] Desplegar al menos una app en Vercel o Netlify

**Recursos gratuitos recomendados:**
- [The Odin Project](https://www.theodinproject.com/) — ruta completa de desarrollo web
- [freeCodeCamp](https://www.freecodecamp.org/) — certificaciones gratuitas
- [javascript.info](https://javascript.info/) — JavaScript en profundidad
- [React Docs](https://react.dev/) — documentación oficial de React
- YouTube: Midudev, Fazt, Hola Mundo (en español)
